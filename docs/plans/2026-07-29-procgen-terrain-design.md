# Procedural Terrain Design (2026-07-29)

Confirmed with daveey. Replaces the two hand-authored arenas as the canonical
map source with a seeded generator + curated pool.

## Decisions (locked)

1. **Pool + overrides**: canonical play draws from a curated pool of 20
   pre-validated seeds. Any parameter can be locked via config (`mapSeed`,
   `mapSize`, `mapSymmetry`, `mapColumns`, `mapWindows`, `mapCenterFeature`,
   `mapPoolIndex`); `mapPath: "gen"` generates from `mapSeed` + overrides,
   `mapPath: "pool"` picks a pool entry (`mapPoolIndex`, else `mapSeed mod 20`).
2. **Symmetry**: per-map coin flip between vertical-mirror and 180°-rotation
   of the generated left half. Both are exactly team-fair.
3. **Scope**: size class, obstacle columns (count, per-column shape/period/
   phase/slot count, clear-mask), glass-window slots, center feature
   (bracket / open ring / wall pair), and 4 health-pack candidate points with
   2 active. Archetype families deferred.
4. **Ship**: canonical (GameVersion bump) after daveey reviews the rendered
   pool (zoomable HTML artifact).

## Generator

- Deterministic splitmix64 RNG over `mapSeed`; no std/random (cross-platform,
  wasm-stable).
- **Size classes**: small (0.85×), standard (1.0× = 1235×659), large
  (1.3× = 1606×858). Clearances (`flagRing`, `captureClear`, spawn pockets)
  and `gunRange` scale with the class.
- **Columns**: N ∈ {4,5,6} x-centers evenly spread between the capture
  column and the flag ring, generated for the LEFT half only. Per column:
  shape family (border-attached rect stubs / diamonds / discs / chevron
  zigzag pairs), vertical period 88..120px, phase offset, and a clear-mask
  dropping 1..slots/2 slots.
- **Windows**: 2..4 surviving slots per half become glass (`window: true`),
  biased toward the outermost column and the midline.
- **Center feature**: windowed bracket (current GV16 geometry), open ring
  (nothing), or solid wall pair straddling the midline.
- **Health packs**: two complementary center-line pairs (y, H-1-y); four
  candidates, one PAIR active. A top/bottom pair on x=W/2 is invariant under
  both mirror and rot180, so pickup fairness holds for either symmetry.
  `CtfMap` gains `medKitCandidates` (4) and `medKitSpawns` (2 active);
  `resetMedKits` reads the map instead of hardcoded thirds.

## Validation (rejection sampling)

Generate → validate → on failure re-roll attempt i as
`splitmix(seed ⊕ i·GOLDEN)`; cap 100 attempts. Validators operate on a
candidate `CtfMap` WITHOUT installing it (parameterized wall test, not the
process globals):

- **Connectivity**: erode wall mask by 13px (half the 26px corridor minimum),
  flood-fill: red spawn pocket ↔ flag ring ↔ both capture columns. This
  enforces both reachability and min corridor width along a route.
- **LOS**: no unblocked straight horizontal crossing between the two capture
  columns on any walkable row (same ray test as `tests/test_map_los.nim`).
- **Cover density**: interior wall-pixel fraction within a band of the
  hand-tuned arena's, so pace doesn't swing wildly.

## Pool

`src/ctf/map_pool.nim`: a generated, dependency-free `const MapPoolSeeds*`
(20 seeds whose maps validate on attempt 0), regenerated by
`tools/gen_map_pool.nim`. Committed so runtime (incl. certifier/wasm) needs
no data file.

## Replay / compat

`configJson` gains `"mapSpec"`: the fully expanded map (dims, clearances,
symmetry, left-half obstacle list, med-kit points). `config.update` prefers
`mapSpec` when present, so replays never re-run the generator — old replays
survive any future generator change. `mapSeed` kept as provenance.
`loadCtfMapMetadata`/`loadCtfMap` gain GameConfig-driven overloads; the
gun-range default in `config.update` resolves through the same path.
